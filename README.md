# 학교장 추천 선발 관리 시스템 (Vue + Supabase 내부망 웹 버젼)

고등학교에서 학교장추천전형 지원자를 공정하게 선발하기 위한 전 과정을 지원하는 내부망 전용 웹 애플리케이션입니다.
Vite + Vue 3 및 Supabase Serverless 클라이언트 구조로 이관 및 단일 폴더 구조로 정리되었습니다.

---

## 🛠️ 주요 아키텍처 및 특징

- **Serverless DB & Storage**: Supabase(PostgreSQL) 데이터베이스와 Storage 객체 스토리지를 활용하여 교사/학생 정보와 실시간 서명 및 포기원 스캔본을 안전하게 저장합니다.
- **실시간 서명 업로드**: 학생 및 보호자의 Canvas 서명을 PNG 파일로 스토리지(`signatures` 버킷)에 직접 업로드합니다.
- **AI OCR 무결성 판독**: 포기원 PDF 업로드 시 브라우저 내에서 렌더링 후 OpenAI GPT-4o-mini Vision API를 사용하여 제출자 인적사항 불일치와 서명 누락을 실시간으로 확인하고 경고합니다.
- **클라이언트 랭킹 계산**: 복잡한 대학/모집단위별 석차 정렬(내신점수순, 재학생 우선, 동점자 보류 처리 등)을 Supabase 데이터에 기반하여 브라우저에서 실시간으로 정밀 연산합니다.
- **A4 인쇄 서식**: 공식 선정 신청서 및 7컬럼 최적화 결과 보고서를 A4 portrait 규격에 맞게 PDF 인쇄할 수 있습니다.

---

## 🚀 개발 서버 구동 방법

루트 폴더에서 개발 서버를 바로 기동할 수 있습니다.

```bash
# 1. 패키지 설치
npm install

# 2. 개발 서버 구동 (기본 포트: 5173)
npm run dev
```

---

## ⚙️ 데이터베이스 & 연동 설정

1. **Supabase 스키마 생성**:
   - 루트 폴더의 `schema.sql` 파일을 복사하여 Supabase SQL Editor에서 실행하면 필요한 테이블, RLS 룰, 트리거 및 암호화 인증용 RPC 함수들이 생성됩니다.
2. **연결 정보 설정**:
   - 시스템 최초 실행 시 로그인 창 및 관리자 화면의 **[환경 설정]** 탭에서 Supabase URL, Anon Key 및 OpenAI API Key를 웹 브라우저 상에서 직접 입력하고 수정할 수 있습니다. (설정 값은 브라우저의 `localStorage`에 자동 보관됩니다.)
